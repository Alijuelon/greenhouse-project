===== 11. KNOWN DEFECTS FOUND (not silently passed) =====
(a) warning/card = 2.043:1 — BELOW the 4.5 AA body floor and below the 3.0
    large-text / UI-component floor. The deliverable lists warning/card as a
    pair that must assert >= 4.5, but `warning` (#FFA000) is a pre-existing
    token this task is forbidden to change ("do not change any existing value
    except textMuted"). Instead of lowering the gate to make it green, the test
    PINS the measured 2.043:1 in a test named "KNOWN DEFECT" and fails if the
    value moves. Palette owner fix: #B45309 -> 5.02:1, #8A5A00 -> 5.93:1.
    => acceptance criterion "all 11 pairs >= 4.5" is NOT met for this one pair;
       10 of 11 are met (7 at 4.5, 3 at the documented 3.0 floor).

(b) accent/accentSoft = 2.82:1 (informational, pair not in the required list).
    Todo 9 specifies a LIVE chip with `accent` text on `accentSoft`; that would
    be below 3:1. Needs a darker accent-on-tint pair before T9 lands.

(c) `dart format --output=none --set-exit-if-changed lib/core/theme test/theme`
    exits 1 because of `lib/core/theme/app_theme.dart`, which was ALREADY
    unformatted in the Wave-0 snapshot (proof in section 5). That file is
    explicitly out of scope for this task, so it was left untouched; the 7
    files this task owns are format-clean (exit 0).

(d) `import 'dart:ui'` was required by the brief, but
    `flutter analyze` reports `unnecessary_import` because
    `package:flutter/material.dart` already re-exports `FontFeature`. The
    import was dropped (with an inline comment naming dart:ui) to keep the
    hard gate "No issues found!". A plain `import 'dart:ui';` would also have
    made `TextStyle` ambiguous.
